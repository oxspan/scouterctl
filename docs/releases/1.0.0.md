# scouterctl 1.0.0

Draft release notes for the first stable release. This document does not mean the release has been published.

scouterctl brings Scouter diagnostics and data extraction to a shared command interface for people, scripts and other tools.

## Included

- Collector/Agent status, settings inspection and real-time counters.
- Stored counter history as JSONL, with units and missing-value metadata.
- Multi-day counter export with checkpointed resume and file integrity checks.
- Transaction, SQL and error profiles; saved captures for offline search, summary and comparison.
- Named connections, explicit terminal password input and noninteractive JSON/JSONL with stable error codes.
- Linux x64 and native Windows x64 command packages: run `scouterctl <command>` with an installed JDK 21.

The explicit 18-release Collector list is validated separately from JVM/Agent/framework combinations. Collector processes can run Java 8 independently of the CLI. See [supported versions](../supported-versions.md).

## Install and upgrade

Download the platform ZIP and `SHA256SUMS` from this release, verify it, extract into a versioned directory and add `bin` to PATH. Keep configuration and captures outside installations. Upgrade by switching PATH; switch back to roll back. See [installation](../installation.md).

Published 0.x POC JAR assets are replaced by command ZIPs for end users. Scripts that downloaded `*-poc.zip` should select the matching `*-linux-x64.zip` or `*-windows-x64.zip`. JDK 21 remains external; Node is not required. Existing XLog capture formats retain their documented read/resume rules, and counter captures use a separate schema.

## Boundaries

Initial platform support is Linux x64 and Windows x64. Active-request snapshots, thread dumps, configuration changes and Agent control remain later work. Keep emoji out of Windows installation paths; Unicode arguments and saved-data paths are supported.

Capture completion means extraction completed, not that telemetry was lossless. Units describe current Collector definitions; missing samples are not zero-filled. Counter export buffers each response, retains completed windows without refreshing late arrivals, and has the limits described in [counter export](../counter-export.md). Collector TCP requires a trusted network or a separately secured tunnel.
